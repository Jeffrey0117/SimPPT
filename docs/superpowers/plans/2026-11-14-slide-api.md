# 逐頁 API／SDK／MCP 與「AI 插入」 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 讓程式與 AI 能對簡報的某一頁下手（SDK、HTTP API、MCP 三個入口），編輯器多一個「AI 插入」，並跟上外部對檔案的修改；簡報副檔名 `.simppt`。

**Architecture:** parser 仍只有 `index.html` 那一份，新增兩個純函式；`lib/parser.mjs` 在 node 裡抽出它；`lib/deck-api.mjs` 是三個入口共用的核心，`lib/api-routes.mjs` 與 `mcp/server.mjs` 各包一層。

**Tech Stack:** Node（零依賴、ESM）、單檔 `index.html`、`node:assert` 測試。

**Spec:** `docs/superpowers/specs/2026-11-14-slide-api-design.md`

## Global Constraints

- 零依賴：不新增任何 npm 套件。
- 對外頁碼從 1 開始，空白頁也算一頁；parser 內部 index 從 0 開始。
- 寫檔一律走 `lib/deck-store.mjs` 的 `writeDeck`。
- 編輯器換掉全文一律走 `replaceEditorText`；新樣式用 `:root` 的 token；圖示用 SVG sprite，不用 emoji。
- 每個測試檔沿用既有的 `tests[]` + 逐一執行的寫法，並加進 `package.json` 的 `test`。

## Review Focus

1. snippet 被 AI 包在 ``` code fence 裡 → 應該剝掉再插入，不是插入一頁程式碼。（Task 1）
2. snippet 帶 frontmatter 或 `set bg=…` → 後面的頁不能變色。（Task 1）
3. 簡報檔名有中文與空白 → API 的 `deck` 參數與 MCP 的名稱比對都要能找到。（Task 2、3）
4. 編輯器有未存修改時外部改檔 → 內容不能被換掉。（Task 6）
5. 存檔後緊接著的那一輪檢查 → 不能把自己剛存的當成「外部新版」。（Task 6）

### Task 1: parser 的 `insertSlidesAfter`、`replaceSlide`

**Files:** Modify `index.html`（`<script id="simppt-parser">`，在 `moveSlide` 後面；return 物件加兩個名字）；Test `test/parser.test.mjs`

**Produces:**
- `insertSlidesAfter(text, index, snippet) → { text, index, count }`；`index = -1` 放最前面；`count = 0` 時 `text` 原樣。
- `replaceSlide(text, index, snippet) → { text, index, count }`；頁不存在或 snippet 沒內容時原樣、`count = 0`。

- [ ] 測試：插在中間／最前／最後；其他頁 `parse(...).slides` 的 `meta`、`body` 不變；新頁沿用當下的 `set` 配色；snippet 的 frontmatter、`set`、code fence、空白頁都被處理掉；`layout=` 留著；取代時保留原分隔線、snippet 有設定時覆蓋同名、多頁時其餘接在後面。
- [ ] 跑測試確認失敗 → 實作（內部 helper：`carriedAt(slides, index)` 算插入點沿用的設定，`snippetSlides(snippet, carried)` 把 snippet 變成 `readPages` 那種頁物件，`want = { ...carried, ...自己的設定 }`）→ 測試通過 → commit。

### Task 2: `lib/parser.mjs`、`lib/deck-api.mjs`、`.simppt` 在伺服器端

**Files:** Create `lib/parser.mjs`、`lib/deck-api.mjs`、`test/deck-api.test.mjs`；Modify `lib/deck-store.mjs`（`MD_RE` 加 `simppt`，匯出 `DECK_RE`）、`server.js`（MIME）、`test/deck-store.test.mjs`、`package.json`

**Produces（`lib/deck-api.mjs`）:**
- `outline(text) → { pages, globals, slides: [{ page, title, layout, lines }] }`
- `readSlides(text, from = 1, to = from) → [{ page, settings, markdown }]`（`markdown` 含該頁自己的分隔線）
- `insertSlides(text, after, markdown) → { text, pages: [新頁碼…] }`
- `replaceSlide(text, page, markdown) → { text, pages }`
- `deleteSlide(text, page) → { text, pages: 剩下的總頁數 }`
- `moveSlide(text, from, to) → { text, page: to }`
- `readDeck(root, rel) → text`、`findDeck(root, query) → rel`、`editDeck(root, rel, fn) → fn 的結果加上 { deck: rel }`（`fn(text)` 回 `{ text, ... }`）
- 錯誤：`Error` 帶 `code`：`ENOPAGE`、`EEMPTY`、`ENODECK`、`EAMBIGUOUS`、`ELASTPAGE`（刪最後一頁）

- [ ] 測試 → 失敗 → 實作 → 通過 → commit。
